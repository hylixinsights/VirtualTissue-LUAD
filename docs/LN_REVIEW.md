# Lessons from VirtualTissue-LN applied to LUAD

Reviewed 30 September 2026 at [LN commit ff8fde3](https://github.com/hylixinsights/VirtualTissue-LN/commit/ff8fde3fae0267645ab75a7e4412e03ae74f4726). These are architectural and presentation lessons. No LN runtime, credentials, cell artwork or biological parameters were imported.

The [continuous-recording guide](https://github.com/hylixinsights/VirtualTissue-LN/blob/ff8fde3fae0267645ab75a7e4412e03ae74f4726/docs/CONTINUOUS_RECORDING.md) makes individual-cell causality easy to inspect: recorded events have chapters, the final state remains accessible, and the inspector exposes the selected cell's permitted actions and receipts. LUAD now adds first-pulse, death-commitment, division, clearance and recruitment chapters, plus next-frame and final-state controls. A chapter is disabled if its event did not occur. The event time and displayed saved-frame time are stated separately. No interpolation invents an event or an intermediate biological state.

The [publication workflow](https://github.com/hylixinsights/VirtualTissue-LN/blob/ff8fde3fae0267645ab75a7e4412e03ae74f4726/docs/PUBLICATION.md) separates the research recorder from the selected static replay. LUAD's new `scripts/build_site.py` follows that boundary: one explicitly selected episode, embedded matching atlas, relative links, provenance, checksums and a restricted file list. The generated page has `connect-src 'none'`; it requires no API key, inference endpoint or Python backend when hosted. Existing local experiment handlers remain inert in the reused player code, and network requests are disabled by the static page policy. Building the package does not publish it.

The mechanism lessons already present in LUAD are independent cell clocks, finite resources, local observations, kernel-authorized menus, a durable paid-response journal and explicit separation of policy choices from physical events. The 5,000-call campaign retains those rules and the validated compression contract. Its main simulation is not stopped when a visually interesting result first occurs, and no prompt is revised mid-trajectory to elicit a desired fate.

The LN's 3D artwork and lymph-node fate rules are unsuitable replacements for measured LUAD geometry. B26 is a 2D Xenium section with competing annotations and limited marker coverage. Its quiet B-cell follicle is not automatically a germinal center, and nuclear-area ratios do not identify migration, killing or division rates. The viewer therefore keeps measured polygons at t=0 and clearly labels subsequent power-cell geometry and modeled fields.

Known differences remain explicit: LUAD currently saves display frames every modeled hour while keeping every 10-minute numerical readout, decision and physical event. It does not claim the LN recorder's lossless frame at every physical tick. Jev questions are batched, up to 20 independent questions per HTTP request; the call count is not the number of cellular decisions.
